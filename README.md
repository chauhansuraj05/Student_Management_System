# 🎓 Student Management System (Java)

A simple **console-based Student Management System** built using **Core Java**.
This project demonstrates CRUD operations with a clean multi-class structure.

---

## 🚀 Features

* ➕ Add Student
* 📄 View All Students
* ✏️ Update Student Details
* ❌ Delete Student
* ⚠️ Input Validation & Exception Handling

---

## 🏗️ Project Structure

```
student/
│
├── Student.java                # Model class (Student data)
├── StudentService.java        # Business logic (CRUD operations)
└── StudentManagementSystem.java # Main class (User Interface)
```

---

## 🧠 Concepts Used

* Object-Oriented Programming (OOP)
* Encapsulation (private fields + getters/setters)
* Collections Framework (`HashMap`)
* Exception Handling (`try-catch`)
* Separation of Concerns (Model, Service, UI)

---

## 🛠️ How to Run

### 1. Compile the project

```bash
javac student/*.java
```

### 2. Run the application

```bash
java student.StudentManagementSystem
```
